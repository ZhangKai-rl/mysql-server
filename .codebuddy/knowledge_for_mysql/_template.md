### XXX（关键环节）

★ **边贴代码边剖析**——贴**完整原代码**，在**关键行附近直接用注释剖析**。不要"整段贴完再在末尾集中写『逐段解释：①…②…』"（解释离对应行太远，读者要来回翻）：

```cpp
// ★ 遍历所有子迭代器，直到候选被足够多的分支确认
while (last_rowid_count < m_children.size()) {
  cmp = cmp_ref(child_rowid, m_last_rowid);

  if (cmp < 0) { child->UnlockRow(); continue; }   // 落后候选 → 解锁后跳过，不阻塞别人
  if (cmp > 0) { /* 换新候选，计数重置 */ }         // 超过当前候选 → 换候选并重置计数
  else last_rowid_count++;                         // 相等 → 该分支确认了候选，计数 +1
}
// ⇒ 为什么必须是这个顺序：先跳过、再换候选、最后计数，保证"计数只在同候选上累加"
```

> 写法：**注释紧贴对应行**（行上方或行尾），讲"做了什么 + 为什么必须这么做 / 边界怎么处理"；**只注释核心与难点，不必逐行**；★ **保持代码完整**——不要为了插解释把函数切碎成多个代码块（打断阅读流、不便复制）；禁止"整段代码 + 末尾『逐段解释：①…②…』"；难点判据＝能解释"为什么不得不这样"；能用 EXPLAIN / trace 印证的就地贴出来对照。
